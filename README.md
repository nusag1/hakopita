# はこぴた

ブロックをはめて列をそろえる、スマホ向けパズルゲーム。

## 遊び方
- 下のブロックをドラッグして 8×8 の盤面にはめる
- 縦か横の1列がそろうと消えて得点
- 続けて消すとコンボ、盤面を空っぽにすると「ぴたっ！」ボーナス（+300）
- どのブロックも置けなくなったら終了

## 特長
- インストール不要。ブラウザで開くだけで遊べる
- ホーム画面に追加すればアプリのように起動でき、オフラインでも遊べる（PWA）
- 途中経過・ハイスコアは端末に自動保存
- 効果音・BGM は WebAudio で合成（音声ファイルなし）

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目（ダークモード対応） |
| `game.js` | ゲーム本体 |
| `sw.js` | オフライン対応（更新時は `VERSION` を上げる） |
| `manifest.webmanifest` | ホーム画面アイコンなどの設定 |
| `icons/` | アプリアイコン |
